01Construction

How it is built

The same skeletons as Hoop, each centred in a 600-unit cell. Wide letters (m, w, M, W) are squeezed horizontally before stroking, so the stroke itself keeps its weight.

Narrow letters get slabs: i, j, l and r would float in a wide cell, so they get feet and flags the way terminal faces do.

A vector face: it works at any size. The tester offers the house steps.
