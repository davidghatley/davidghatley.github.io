01Construction

How it is built

Every letter and figure has three cuts, each turned, nudged and scaled a little differently from a seed. A contextual-alternates feature (calt) cycles through them, so 'oooo' sets three different o's before it repeats.

Underneath it is Hoop at 150 units with slightly squared bowls, so the bounce sits on a steady skeleton.

A vector face: it works at any size. The tester and the waterfall use the house steps.
