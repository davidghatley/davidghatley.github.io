01Construction

How it is built

Pip 57's 5×7 drawings, but cells are joined centre to centre instead of drawn as dots. Each join is a corridor 72 units wide with 20-unit walls.

Corners and junctions stay open inside, and only the free ends are walled, so you could trace each letter with a pencil.

A vector face: it works at any size. The tester and the waterfall use the house steps.
