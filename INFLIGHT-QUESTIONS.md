# Questions to add when you claim the review in the Inflight widget

Inflight lets you ask specific questions and run polls, reviewers pin notes to real elements, and anyone can
leave a video walkthrough in the same link. Each question below uses one of those features on purpose, so the
review doubles as a demo of the product, and each answer is something you can act on.

1. **Pin it: does the first viewport say what I'd be hired for?** (pinned to the H1)
   "You've said the H1 is the most valuable real estate on the site. In five seconds, what would you hire me
   for? Pin the exact word you'd change." *(Uses element-pinned notes on the live page.)*

2. **Poll: which piece should lead?**
   Options: the 3D-to-anime pipeline · VAASF (paid client work) · napkin · bonfire / the kitchen stack.
   "People take the average, not the sum. Which one raises my average most, and which one would you cut?"
   *(Uses polls; the answer reorders the site.)*

3. **Pin it: one creative idea, or the over-designed middle?** (pinned to an open index row)
   "Every project opens into its own custom preview and case page. Is that the one creative idea set against
   restraint, or does it make you work for it? If it loses you, pin the moment." *(Element pins on a live,
   interactive page, not a screenshot.)*

4. **Video note: which one would you want to see a 60-second walkthrough of?** (a video reply is welcome)
   "Pick one project and tell me what you'd want to see in a short walkthrough, or record a quick reaction
   instead of typing." *(Uses Inflight's video feedback in the same link.)*

5. **What would you hand to my coding agent?**
   "Leave your notes as next steps. I'll pull them over Inflight's MCP into Claude Code and ship V2 on the same
   link, so you can see the diff next time." *(Shows off next steps for agents over MCP plus version history,
   and closes the loop on camera.)*

Keep it to 3-5 questions. If you have to cut, keep 1, 2 and 5.
