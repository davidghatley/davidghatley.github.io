Prepares any task into a folder an agent can start from.

The target: give it any task and it lays out a prep folder whose index.md records each item's source and status, before the agent starts. Today a small command line and five Claude Code skills do that, and two example folders were recorded from real agent runs.

What exists is the intent, a landing page, a manual, and a short list of lessons borrowed from my earlier research repos, including one finding that packing evidence loses more than searching for it.

I learned to write down what a tool is not. It is not an agent harness and not the decision model.
